Why it's different

Bring your own key

Pick Claude, Azure OpenAI or OpenAI in Settings. Your key stays on your machine, and you only pay for what you use.

No sign-in, safely

Local mode skips the sign-in screen, and only answers requests from your own computer. The app refuses to start if it's exposed publicly.

Every app stands alone

Each app has its own frontend, backend and database. Nothing is shared, so you can use one, or all 28.

The launcher

One window, every app

Start, stop, restart and open any of the 28 apps. It frees each app's ports before starting, so a stuck app never blocks you.

Talks to Claude Code

If Claude Code is installed on your computer, chat with it right inside the launcher.

From your phone

Turn on phone access, enter the pairing code shown in the launcher, and use it from any phone on the same Wi-Fi. It's off by default.

Get started

  1. Install the tools

    You need Node.js 20+ and the .NET 8 SDK. For the Claude chat, also Claude Code (optional).

  2. Download and open the launcher

    git clone https://github.com/kartik-ramachandran/app-suite.git
cd app-suite/launcher
npm install
npm start

  3. Add your AI key

    Open Settings in the launcher and paste a Claude, Azure OpenAI or OpenAI key.

  4. Start an app

    Go to Apps, press Start, then Open. The first start of each app installs its packages, so give it a minute.

Prefer one app on its own? Every app folder has a README with its ports, settings and how to run it by hand, for example: LocalMode__Enabled=true Anthropic__ApiKey=<your key> dotnet run.
